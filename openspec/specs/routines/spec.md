## Requirements

### Requirement: Routines
The system SHALL let the user save a finished workout or a new list of exercises as a named routine, start a workout from it with set counts and rest timers prefilled, and delete it. A workouts hub SHALL list routines and recent workouts.

#### Scenario: Save and start
- **WHEN** the user saves a workout as routine "Leg day" and later taps Start
- **THEN** the logger opens with the same exercises
