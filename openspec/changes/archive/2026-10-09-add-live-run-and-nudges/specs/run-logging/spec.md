# Spec Delta

## ADDED Requirements

### Requirement: Weekly distance history
The system SHALL show the total distance for each of the last 8 Monday-based weeks on Profile, oldest to newest, and highlight the current week.

#### Scenario: History
- **WHEN** the user ran 20 km last week and 5 km this week
- **THEN** the last two bars represent 20 km and 5 km and the current week is highlighted
