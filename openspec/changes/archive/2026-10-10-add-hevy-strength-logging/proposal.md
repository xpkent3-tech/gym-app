## Why
Strength logging is basic (kg/reps only). Hevy-style lifters expect a live logger with previous-set hints, set types, rest timers, notes, routines, per-exercise progress charts, PRs, estimated 1RM, custom exercises and full history.

## What Changes
- Live logger: Time/Volume/Sets header, SET | PREVIOUS | KG | REPS | ✓ rows, W/D/F set types, per-exercise rest timer with automatic countdown, exercise notes, live PR toast.
- Routines: save a workout as a routine, create routines, start from a routine.
- Exercise progress: Summary / History / How-to tabs, charts (heaviest weight, one-rep max, best set volume), PR medals, complete history.
- Custom exercises with equipment and muscles.
- Workout summary screen with PRs; workouts hub.
- Exercise videos are NOT included (no licensed footage); How-to uses cues and a muscle diagram.

## Impact
- Specs: strength-training (modified), exercise-progress, routines (new).
- Data: sets gain `type`; exercise entries gain `note`/`restSec`; sessions gain `durationSec`; store gains `routines` and `customExercises`.
